USERS GUIDE

System Requirements

To access the STICA Marketing Ecosystem, you need:

  • A modern web browser (Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari)
  • An active internet connection
  • Valid user credentials provided by the system administrator
  • Microsoft 365 account (for authentication)

1. Logging Into the System

1. Launch the System:

  • Open your web browser and navigate to the STICA Marketing Ecosystem URL provided by your administrator.

2. Microsoft 365 Login:

  • You will be redirected to the login page.
  • Enter your registered email address and password.
  • Click Sign in with Microsoft 365 to authenticate.
  • Upon successful authentication, you will be redirected to your respective dashboard based on your role.

3. User Roles:

The system supports the following user roles:

  • Superadmin - Full system access and administrative privileges
  • Admin - Access to assigned modules based on permissions

2. User Roles and Features

A. Superadmin

The Superadmin has full access to all system functionalities and administrative privileges. This role is responsible for managing the entire system, including user accounts, permissions, and system-wide configurations.

Key Features:

  • Create, edit, and delete admin user accounts
  • Assign module permissions to admin users (Inquiries, Enrollment, Marketing Activities, Schools)
  • View all admin accounts and their assigned permissions
  • Generate comprehensive system reports
  • Access all modules without restrictions

How to:

Add Users:

  • Navigate to Superadmin Dashboard
  • In the "Create New Admin" section, enter the following:
    • Email address (must be unique and valid)
    • First Name
    • Last Name
  • Select the modules you want to grant access to by checking the boxes:
    • Inquiries
    • Enrollment
    • Marketing Activities
    • Schools
  • Click Create Admin
  • The system will generate a temporary password that you can share with the new admin user
  • The new admin will receive an email with their login credentials (if email is configured)

Edit User Permissions:

  • Navigate to Superadmin Dashboard
  • Locate the admin user in the "Admin Accounts" table
  • Click the Edit button (pencil icon) next to the user
  • Modify the module permissions by checking or unchecking the appropriate boxes
  • Click Update Admin to save changes

Delete Users:

  • Navigate to Superadmin Dashboard
  • Locate the admin user in the "Admin Accounts" table
  • Click the Delete button (trash icon) next to the user
  • Confirm the deletion in the dialog box
  • The user account will be permanently removed from the system

B. Admin

The Admin role has access to specific modules based on permissions assigned by the Superadmin. Admins can manage inquiries, enrollments, marketing activities, and schools within their assigned modules.

Key Features:

  • Access to Dashboard with analytics and statistics
  • Manage student inquiries (if Inquiries permission is granted)
  • Manage student enrollments (if Enrollment permission is granted)
  • Track marketing activities and campaigns (if Marketing Activities permission is granted)
  • Manage feeder schools, competitor schools, and non-feeder schools (if Schools permission is granted)
  • Update personal profile and settings
  • View reports and analytics for assigned modules

Module Access:

Admins can only access modules that have been assigned to them by the Superadmin. The available modules are:

  • Dashboard - Always accessible, provides overview of inquiries, enrollments, and key metrics
  • Inquiries - Manage student inquiries and track inquiry status
  • Enrollment - Manage student enrollments and enrollment records
  • Marketing Activities - Track marketing campaigns, leads, and ROI
  • Schools - Manage feeder schools, competitor schools, and non-feeder schools
  • Settings - Update profile information and preferences

3. Dashboard Module

The Dashboard provides a comprehensive overview of key metrics, statistics, and analytics for the marketing ecosystem.

Key Features:

  • View total inquiries and enrollments count
  • Monitor year-over-year and month-over-month growth percentages
  • View upcoming marketing activities
  • Analyze top preferred courses and strands
  • Track enrollment distribution by program and strand
  • View marketing source effectiveness and conversion rates
  • Access time-series charts for inquiries and enrollments

How to:

Filter Data by Date Range:

  • Navigate to Dashboard
  • Use the date range picker at the top of the page
  • Select a start date and end date
  • All statistics and charts will automatically update to reflect the selected date range

View Detailed Analytics:

  • Navigate to Dashboard
  • Scroll down to view various chart sections:
    • Inquiries and Enrollments Trends - Line charts showing trends over time
    • Top Courses/Strands - Bar charts showing most preferred programs
    • Source Effectiveness - Pie charts showing marketing source performance
  • Use the period selector (Week, Month, Year) to change the time period for charts

4. Inquiries Module

The Inquiries module allows admins to manage student inquiries, track inquiry status, and convert inquiries to enrollments.

Key Features:

  • Create new student inquiries
  • View and search inquiry records
  • Update inquiry status and information
  • Filter inquiries by student type, status, and date range
  • Convert inquiries to enrollments
  • View inquiry details and notes
  • Track inquiry sources and referral information

How to:

Create a New Inquiry:

  1. Navigate to Inquiries from the sidebar
  2. Click the Add Inquiry button
  3. Fill in the required information:
    • Inquiry Type (Walk-in, Phone, Email, Online, etc.)
    • Student Type (Tertiary/College or Senior High)
    • First Name and Last Name
    • Email Address
    • Mobile Number
    • Present School (if applicable)
    • Program(s) of interest
    • How did you find out about us (marketing sources)
    • Referral source (if applicable)
    • Inquiry Date
  4. Click Submit Inquiry to save

Update Inquiry Status:

  • Navigate to Inquiries
  • Locate the inquiry in the table
  • Click the Edit button (pencil icon) next to the inquiry
  • Update the status field (For follow up, Reserved, Enrolled, Enrolled to other STI, Enroll to other school, Undecided)
  • Add or modify notes if needed
  • Click Update Inquiry to save changes

Convert Inquiry to Enrollment:

  • Navigate to Inquiries
  • Locate the inquiry you want to convert
  • Click the Enroll button next to the inquiry
  • Confirm the enrollment in the dialog box
  • Fill in any additional enrollment information required
  • The inquiry will be converted to an enrollment record

Filter and Search Inquiries:

  • Use the search box to search by name, email, or program
  • Use the Student Type filter to show only College or Senior High inquiries
  • Use the Status filter to show inquiries by status
  • Use the date range picker to filter inquiries by date

5. Enrollment Module

The Enrollment module allows admins to manage student enrollment records, track enrollment statistics, and categorize students by type.

Key Features:

  • Create new enrollment records
  • View and search enrollment records
  • Edit enrollment information
  • Delete enrollment records
  • Filter enrollments by student type (All, Freshmen, Transferees, STI Transferees)
  • View enrollment statistics (Total Enrolled, New Enrollments, Conversion Rate, Most Enrolled Program)
  • Track enrollment by program and strand

How to:

Add a New Enrollment:

  1. Navigate to Enrollment from the sidebar
  2. Click the Add Student button
  3. Fill in the student information:
    • Type of Student (College or Senior High)
    • Student Classification (Freshman, Transferee, STI Transferee - for College students)
    • Student Number (required for STI Transferees, must be 11 digits)
    • First Name, Middle Name, Last Name
    • Date of Birth
    • Civil Status
    • Gender
    • Contact Information (Landline, Mobile Number, Email)
    • Last School Attended
    • School Name (if applicable)
    • Program(s) or Strand(s)
  4. Click Add Student to save the enrollment

Edit an Enrollment:

  • Navigate to Enrollment
  • Locate the enrollment record in the table
  • Click the Edit button (pencil icon) next to the record
  • Modify the information as needed
  • Click Update Student to save changes

View Enrollment Statistics:

  • Navigate to Enrollment
  • View the statistics cards at the top of the page:
    • Total Enrolled - Total count of all enrolled students
    • Students Added This Year - Count of students enrolled in the current year
    • Conversion Rate - Percentage of inquiries converted to enrollments
    • Most Enrolled Program - Program with the highest number of enrollments

Filter Enrollments by Student Type:

  • Navigate to Enrollment
  • Use the tabs at the top of the table:
    • Enrolled - Shows all enrolled students
    • Freshmen - Shows only freshman students
    • Transferees - Shows only transferee students
    • STI Transferee - Shows only STI transferee students

6. Marketing Activities Module

The Marketing Activities module allows admins to track marketing campaigns, monitor lead generation, and analyze marketing ROI and conversion rates.

Key Features:

  • Create and manage marketing activity records
  • Track leads generated from each activity
  • Monitor marketing budget and spending
  • Calculate cost per lead and campaign ROI
  • View conversion rates by event
  • Filter activities by time period (All, This Week, This Month, Next Month)
  • Associate activities with feeder schools
  • Manage event titles

How to:

Add a Marketing Activity:

  1. Navigate to Marketing Activities from the sidebar
  2. Click the Add Activity button
  3. Fill in the activity details:
    • Title of Event - Select from existing titles or create a new one
    • School - Select the feeder school associated with the activity (optional)
    • Date - Select the date of the activity
    • Budget - Enter the budget amount (e.g., ₱250,000)
    • Leads Generated - Enter the number of leads generated from this activity
  4. Click Add Activity to save

Create a New Event Title:

  • When adding or editing a marketing activity, in the "Title of Event" dropdown, select Add Activity
  • Enter the new event title in the input field
  • Click Add to create the new title
  • The new title will be available for selection in future activities

View Marketing Metrics:

  • Navigate to Marketing Activities
  • View the metrics cards at the top:
    • Lead Generation - Total leads generated in the selected period
    • Cost per Lead - Average cost per lead (Total Budget / Total Leads)
    • Campaign ROI - Leads per graduating student
    • Conversion Rate - Percentage of leads converted to enrolled students (click to view detailed breakdown)

View Conversion Rate by Event:

  • Navigate to Marketing Activities
  • Click on the Conversion Rate card
  • A dialog will open showing:
    • Bar chart displaying conversion rates for each marketing event
    • Event details with leads generated and conversion percentages
    • Summary statistics (Total Events, Total Leads, Average Rate)

Filter Activities by Time Period:

  • Navigate to Marketing Activities
  • Use the tabs above the activities table:
    • All - Shows all marketing activities
    • This Week - Shows activities from the current week
    • This Month - Shows activities from the current month
    • Next Month - Shows activities scheduled for next month

7. Schools Module

The Schools module allows admins to manage feeder schools, competitor schools, and non-feeder schools, including their courses, student counts, and other relevant information.

Key Features:

  • Create and manage school records
  • Categorize schools as Feeder, Competitor, or Non-Feeder
  • Add courses offered by feeder schools
  • Track student counts (Grade 10 and Grade 12) for feeder schools
  • Record competitor school information (building/grounds, campus size, facilities, tuition fees)
  • Filter schools by type, status, and school type (Public/Private)
  • Search schools by name

How to:

Add a Feeder School:

  1. Navigate to Schools from the sidebar
  2. Click the Add School button
  3. Select Feeder School as the school type
  4. Fill in the school information:
    • School Name
    • Distance (km away from your school)
    • Type of School (Public or Private)
    • Total Students for Grade 10
    • Total Students for Grade 12
    • Description (optional)
  5. Add courses offered:
    • Click Add Course
    • Enter the course name
    • Enter the estimated tuition fee
    • Repeat for additional courses
  6. Select the school status (Active or Inactive)
  7. Click Add School to save

Add a Competitor School:

  1. Navigate to Schools
  2. Click the Add School button
  3. Select School Competitor as the school type
  4. Fill in the school information:
    • School Name
    • Distance (km away)
    • Type of School (Public or Private)
    • Building or Grounds (B for Building, G for Campus Grounds)
    • Campus Size (L for Larger, E for Equal, S for Smaller than your campus)
    • Facilities (B for Better, E for Equal, P for Poorer compared to your campus)
    • Estimated Total Tuition Fee per Term/School Year
  5. Select the school status (Active or Inactive)
  6. Click Add School to save

Edit a School:

  • Navigate to Schools
  • Locate the school in the appropriate tab (Feeder Schools, Competitors, or Non-Feeder Schools)
  • Click the Edit button (pencil icon) next to the school
  • Modify the information as needed
  • For feeder schools, you can add, edit, or remove courses
  • Click Update School to save changes

Filter Schools:

  • Use the search box to search schools by name
  • Use the Status filter to show only Active or Inactive schools
  • Use the School Type filter to show only Public or Private schools
  • Use the tabs to view schools by category (Feeder Schools, Competitors, Non-Feeder Schools)

8. Settings Module

The Settings module allows admins to update their profile information, manage notification preferences, and change their password.

Key Features:

  • Update profile information (First Name, Last Name)
  • Manage notification preferences
  • Change account password
  • Toggle dark mode/light mode

How to:

Update Profile Information:

  • Navigate to Settings from the sidebar
  • In the "Profile Settings" section, update your First Name and Last Name
  • Click Save Changes to update your profile

Change Password:

  • Navigate to Settings
  • In the "Security Settings" section, enter:
    • Current Password
    • New Password
    • Confirm New Password
  • Click Change Password to update

Toggle Dark Mode:

  • Navigate to Settings
  • In the "Appearance Settings" section, toggle the Dark Mode switch
  • The interface will immediately switch between light and dark themes

9. Logging Out

To log out of the system:

  • Click the Logout button located at the bottom of the sidebar
  • You will be redirected to the login page
  • For security, always log out when you are finished using the system

10. Troubleshooting

Common Issues:

Cannot Log In:

  • Verify that you are using the correct email address and password
  • Ensure your Microsoft 365 account is active
  • Contact your system administrator if you have forgotten your password
  • Clear your browser cache and cookies, then try again

Module Not Visible:

  • If a module is not visible in the sidebar, you may not have permission to access it
  • Contact your Superadmin to request access to the module
  • The Superadmin can assign module permissions through the Superadmin Dashboard

Data Not Updating:

  • Click the refresh button (circular arrow icon) in the top-right corner of the page
  • Check your internet connection
  • Try logging out and logging back in
  • If the issue persists, contact your system administrator

Error Messages:

  • Read the error message carefully - it usually indicates what went wrong
  • Common errors include:
    • Required fields not filled - Ensure all required fields are completed
    • Invalid email format - Check that email addresses are correctly formatted
    • Duplicate entries - Some fields (like email) must be unique
    • Network errors - Check your internet connection
  • If you cannot resolve the error, contact your system administrator with the error message

11. Support and Contact

For technical support, questions, or to report issues:

  • Contact your system administrator
  • Reach out to the IT support team
  • Provide detailed information about the issue, including:
    • What you were trying to do
    • What error message (if any) you received
    • Your user role and email address
    • Screenshots of the issue (if applicable)
